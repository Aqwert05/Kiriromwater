# KIRIROM Natural Mineral Water Website

A simple, professional static product website for the Cambodian local market. It is ready to upload to GitHub and deploy on Vercel as a plain HTML/CSS/JavaScript site.

## Files

- `index.html` — complete responsive website with hero banner, product sizes, brand story, benefits, customer use cases, contact buttons, and English/Chinese/Khmer language switching.
- `assets/products/` — product renderings for 330ml, 500ml, 1L, 5L, 15L, plus a family product image.
- `assets/posters/` — homepage poster artwork.
- `scripts/generate_kirirom_assets.py` — optional script for regenerating the SVG product and poster assets.

## Deploy to Vercel

1. Upload this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Use the default static project settings. No build command is required.
4. Deploy.
